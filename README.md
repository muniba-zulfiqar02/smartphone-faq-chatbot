# 📱 Smartphone FAQ Chatbot

An NLP-powered chatbot built with Python and Flask that answers user questions by finding the most similar FAQ using TF-IDF and Cosine Similarity.

## 🔧 Technologies Used
- Python
- Flask
- NLTK
- Scikit-learn (TF-IDF + Cosine Similarity)
- HTML, CSS, JavaScript

## 🚀 How to Run
1. Install dependencies: pip install nltk scikit-learn flask
2. Run: python app.py
3. Open browser: http://127.0.0.1:5000
